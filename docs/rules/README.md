# Rules

What holds in Isoloop today, one fact per rule, with every decision that touched it. Generated by `pnpm rules:build` from the JSON files in this folder ([ADR 0026](../adr/0026-rules-registry.md)); edit those, not this file. `pnpm rules:board` opens the same data as a board.

## Isolates

What an isolate is, how it starts and stops, and the worker it runs in. Prefix `iso`.

No rules yet.
