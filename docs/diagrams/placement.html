How to read it

  • A box is a thread. The same three isolates run on the left in three own workers and on the right as members of one pool.
  • Placement is the host manifest's choice alone: the isolate's code is the same either way (ADR 0001, ADR 0015).

What a pool saves

  • 20 headless isolates in one worker: 71–86% less memory and 2–3× faster start-up than 20 own workers (ADR 0001 gate).
  • 8 React widgets in one worker: 35–64% less memory, with the same p95 from publish to applied patch (ADR 0015 gate).

What members share

  • One event loop and its timers: a member that blocks stalls the others.
  • globalThis and the built-ins, frozen before the first member loads; the properties V8 protects stay plain data (ADR 0001 amendment).
  • One isoloop-dom document, a root per visual member: members can read each other's DOM and input (ADR 0015).
  • Fate: a worker error or a missed heartbeat restarts every member together in a new worker; a member's own fatal error restarts only that member.

What stays per isolate

  • Its bus port, grants, subscriptions and committed offsets.
  • Its surface, compositor queue and frame budget.
  • Its supervisor state and restart count.
