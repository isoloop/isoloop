How to read it

  • A box is a thread: the main thread, an own worker, a pool's worker or the bus worker. A card inside a worker is one isolate or a group of them, with the count on the card.
  • Every isolate talks to the bus worker over its own MessageChannel port, never through the main thread (ADR 0005).
  • The main thread only applies patches and runs the kernel; isolate code never runs there.

Ports

  • Isolate port: init, event, result, shutdown, reattach in; ready, patch, call, beat, error, bye out. In a pool every message names its member, except beat, which is the worker's.
  • Bus port: publish, subscribe, unsubscribe, commits, request, reply in; deliver, reset, result out. commits carries every subscription's settled offset, at most once per commitIntervalMs (ADR 0016).
  • Control port: boot, attach, detach, publish, flush, drop in; ready, beat, wake, metrics, result, seed, error out.

Start-up

  • createKernel throws unsupported_browser when module workers, MessageChannel, adopted stylesheets or OPFS are missing.
  • A worker's entry is tiny and imports the bootstrap, which starts once per worker even if WebKit evaluates the entry twice.
  • A pool freezes the built-ins before its first member loads, leaving the properties V8 protects as plain data (ADR 0001 amendment).

The bus worker

  • Started before any isolate and supervised like one: beats, restarts, and after two crashes while loading, a safe-mode boot that sets the newest segment aside.
  • After a restart, isolates get a new port (reattach) and keep running. Past the restart limit the bus is failed: isolates keep running and their bus calls reject with bus_unavailable.
  • Persistent topics need the isoloop-bus Web Lock and sync access handles; without them they run in memory and the kernel emits bus:durability-degraded.
