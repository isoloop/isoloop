Isolates aren't restarted

  • A bus crash restarts only the bus worker: each isolate gets a new port and keeps its state (ADR 0007).
  • An isolate whose manifest sets bus.onReset: 'restart' is restarted instead.
  • Past the restart limit the bus is failed: isolates keep running and their bus calls reject with bus_unavailable. A contracts error fails every isolate at once, with no retry.

What comes back

  • Persistent topics resume from their committed offsets; a re-sent publish already on disk isn't appended twice.
  • Memory topics are gone: each subscription gets one reset, and adapters clear and refill from earliest.
  • The new bus starts with an empty route topic; the kernel publishes the current route again.
