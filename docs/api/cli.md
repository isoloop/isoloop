# The isoloop command line

Every command of `isoloop`, with its usage and its flags, as its own `--help` gives them.

## Options for every command

| Flag | Description |
| --- | --- |
| `-h, --help` | Show help (also after a command). |
| `-v, --version` | Show the version. |

## `isoloop contracts export`

Write JSON Schema for every topic in a contracts module.

```sh
isoloop contracts export <module> [options]
```

\<module> is the contracts module: its default export is made by contracts(). Prints the JSON document, or writes it with --out. Exits 1 when a topic's schema can't be made into JSON Schema.

| Flag | Description |
| --- | --- |
| `-o, --out <file>` | Write to a file instead of stdout. |
| `-h, --help` | Show this help. |

## `isoloop mcp`

Run the dev MCP server: the tools of pages in development, for agents.

```sh
isoloop mcp [options]
```

Speaks MCP over stdio. Pages connect to ws://127.0.0.1:\<port> with connectDevMCP(kernel, { url, token }) from '@isoloop/host/dev-mcp'. The token is printed on stderr, or fixed with ISOLOOP_MCP_TOKEN.

Claude Code: claude mcp add isoloop -- npx isoloop mcp

| Flag | Description |
| --- | --- |
| `--port <port>` | The WebSocket's port on 127.0.0.1 (default 4317; 0 picks a free one). |
| `--origin <patterns>` | Origins pages may connect from, comma separated, * for any run (default http://localhost:*). |
| `--allow-write` | Also offer the tools that change something (readOnly: false). |
| `-h, --help` | Show this help. |

## `isoloop migrate`

Rewrite your source for an Isoloop release that changed an API.

```sh
isoloop migrate [version] [options]
```

Starts from the installed @isoloop/* version (or --from) and runs each step up to [version], by default the newest this CLI knows. Reads the .ts, .tsx, .mts, .cts, .js, .jsx, .mjs, .cjs files under the working directory (or --dir), outside node_modules and dot-folders. Prints the changes as a diff and writes nothing, unless --write is given. Code it can't rewrite safely gets a "// isoloop-migrate:" comment above it, listed at the end. Run it before you upgrade, or pass --from with the version you upgraded from. Exits 1 when a file doesn't parse; that file is left as it is.

| Flag | Description |
| --- | --- |
| `--write` | Write the changes to the files. |
| `--from <version>` | The version the code is written for (default: the installed one). |
| `--dir <folder>` | The folder to migrate (default: the working directory). |
| `-h, --help` | Show this help. |

## `isoloop skill add`

Copy the "build with Isoloop" skill into your project, for coding agents.

```sh
isoloop skill add [options]
```

Writes build-with-isoloop/SKILL.md into .claude/skills in the working directory, or into --dir. The skill is the one that shipped with this CLI's version. Exits 1 when a different copy is already there, unless --force is given.

| Flag | Description |
| --- | --- |
| `--dir <folder>` | The skills folder to copy into (default .claude/skills). |
| `--force` | Replace a copy that differs. |
| `-h, --help` | Show this help. |
