# The isoloop command line

Every command of `isoloop`, with its usage and its flags.

`isoloop --help` lists the commands, `isoloop <command> --help` shows one, and `isoloop --version` prints the version.

## `isoloop contracts export`

Write JSON Schema for every topic in a contracts module.

```sh
isoloop contracts export <module> [options]
```

\<module> is the contracts module: its default export is made by contracts(). Prints the JSON document, or writes it with --out. Exits 1 when a topic's schema can't be made into JSON Schema.

| Flag | Description |
| --- | --- |
| `-o, --out <file>` | Write to a file instead of stdout. |
| `-h, --help` | Show this help. |

## `isoloop mcp`

Run the dev MCP server: the tools of pages in development, for agents.

```sh
isoloop mcp [options]
```

Speaks MCP over stdio. Pages connect to ws://127.0.0.1:\<port> with connectDevMCP(kernel, { url, token }) from '@isoloop/host/dev-mcp'. The token is printed on stderr, or fixed with ISOLOOP_MCP_TOKEN.

Claude Code: claude mcp add isoloop -- npx isoloop mcp

| Flag | Description |
| --- | --- |
| `--port <port>` | The WebSocket's port on 127.0.0.1 (default 4317; 0 picks a free one). |
| `--origin <patterns>` | Origins pages may connect from, comma separated, * for any run (default http://localhost:*). |
| `--allow-write` | Also offer the tools that change something (readOnly: false). |
| `-h, --help` | Show this help. |
