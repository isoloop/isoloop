# @isoloop/devtools

The devtools panel: `connectDevtools` and its options.

## `@isoloop/devtools`

### `connectDevtools`

**Experimental.**

Connects the devtools panel: a surface covering the viewport that takes no
pointer events itself (the panel's boxes are `position: fixed`), and the
panel isolate in its own worker with the `inspect` grant (never pooled).
Alt+Shift+D toggles it. Guide: `docs/guide/devtools.md`.

```ts
import { connectDevtools } from '@isoloop/devtools';
const disconnect = connectDevtools(kernel, { position: 'bottom-left' });
```

The floating button and Alt+Shift+D open and close it.

```ts nocheck
function connectDevtools(kernel: Kernel, o?: DevtoolsOptions): () => Promise<void>;
```

**Returns:** A function that disconnects: it stops the panel isolate and
removes its surface, resolving once the worker is gone.

**Guides:** [Devtools panel](../guide/devtools.md).

### `DevtoolsOptions`

**Experimental.**

```ts nocheck
type DevtoolsOptions = {
  src?: string;
  position?: DevtoolsPosition;
  healthStatus?: HealthStatus;
  id?: string;
};
```

| Field | Description |
| --- | --- |
| `src?` | The panel isolate's module URL. Defaults to the `panel.js` next to this module in the published package, which `@isoloop/vite` serves in dev and Vite emits in a build. With another bundler, pass the URL it serves `@isoloop/devtools/panel` at. |
| `position?` | Where the closed button and the opened panel sit. Default `'bottom-right'`. |
| `healthStatus?` | How the closed button shows the kernel's health. Default `'ring'`. |
| `id?` | The panel isolate's id in the kernel. Default `'isoloop-devtools'`. |

**Guides:** [Devtools panel](../guide/devtools.md).

### `DevtoolsPosition`

**Experimental.**

The corner the floating button and the docked panel sit in.

```ts nocheck
type DevtoolsPosition = "bottom-right" | "bottom-left" | "top-right" | "top-left";
```

**Guides:** [Devtools panel](../guide/devtools.md).

### `HealthStatus`

**Experimental.**

How the closed button shows the kernel's health:
- `'ring'`: a ring of twelve arcs, one stretch of isolates each, coloured by
their worst state, with a wave of brightness running round it;
- `'radar'`: the same ring, with the logo filled by the same twelve colours;
- `'off'`: a plain white ring, with no status on the button.

```ts nocheck
type HealthStatus = "ring" | "radar" | "off";
```

**Guides:** [Devtools panel](../guide/devtools.md).
