# isoloop

The Isoloop command line: export contracts as JSON Schema, run the dev MCP server for coding agents, add the "build with Isoloop" agent skill to your project, and rewrite your code for a release that changed an API.

```sh
npm install -D isoloop
```

```sh
npx isoloop skill add
```

The guides: [Getting started, for agents working on your app](https://isoloop.dev/docs/getting-started/#for-agents-working-on-your-app) and [Upgrading](https://isoloop.dev/docs/getting-started/#upgrading). Every command and flag: [the isoloop command line](https://isoloop.dev/docs/api/cli/).
