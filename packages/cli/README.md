# isoloop

The Isoloop command line: export contracts as JSON Schema, run the dev MCP server for coding agents, and add the "build with Isoloop" agent skill to your project.

```sh
npm install -D isoloop@next
```

```sh
npx isoloop skill add
```

The guide: [Getting started, for agents working on your app](https://isoloop.dev/docs/getting-started/#for-agents-working-on-your-app). Every command and flag: [the isoloop command line](https://isoloop.dev/docs/api/cli/).
